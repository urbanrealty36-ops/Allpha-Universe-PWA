# V2.13D.6 — Production PWA / Browser Runtime Verification

## Objective
Continue the locked V2.13D.5 activation chain into the real production PWA/browser and prove that the authoritative runtime asset path is consumed by an actual browser viewport.

## Canonical prerequisite
- V2.13D.4: 100 macro assets explicitly promoted to production Storage / `theme_assets`.
- V2.13D.5: 25 themes × 4 macro assets verified through canonical FastAPI manifests, signed URLs, and GLB binary access.
- V2.13D.5 remains LOCKED/GREEN and is not rerun.

## Scope
Only production PWA/browser verification:
1. Railway PWA is reachable.
2. Mobile Universe surface renders a WebGL canvas.
3. Desktop Universe surface renders a WebGL canvas.
4. A production World surface renders through `AllphaWorldRenderer`.
5. Browser network actually fetches a `.glb` asset with HTTP 200/206.
6. No browser page errors or console errors occur during the gate.

No changes to:
- V2.13D.3A/D3C/D3D
- V2.13D.4 Storage or `theme_assets`
- 350-asset production matrix
- Supabase schema
- privileged frontend mutations.

## Runtime chain under test
`Production browser → Railway PWA → WorldExperience → AllphaWorldRenderer → FastAPI runtime manifest → signed GLB URL → Supabase Storage`

## Required runtime input
The browser gate needs an authoritative production World:
- `ALLPHA_PRODUCTION_WORLD_ID`, or
- `ALLPHA_PRODUCTION_WORLD_URL`.

This is intentionally not fabricated. If neither is supplied, the World/GLB gate fails rather than inventing a world record.

## Evidence
The workflow uploads:
`v2-13d6-production-pwa-browser-runtime-report.json`

The report records HTTP status, viewport, canvas/WebGL detection, browser-fetched GLB responses, runtime errors, and final decision.

## Gate
GREEN requires:
- production PWA reachable;
- mobile Universe WebGL PASS;
- desktop Universe WebGL PASS;
- production World WebGL PASS;
- browser fetched at least one GLB with status 200/206;
- zero console/page errors.

This phase does not infer visual quality from HTTP success. Human visual review remains a separate authority.
