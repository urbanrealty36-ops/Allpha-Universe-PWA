# V2.13D.3C — Cinematic Visual Fidelity Remediation

## Objective

Remediate the **100 world-scale assets only** after V2.13D.3B human review rejected the D3A output.

The D3B failure was not an asset-count failure. The common procedural macro composition remained visually dominant, so theme identity, silhouette, negative space and category fidelity were not strong enough against the Crystal AI City Golden Benchmark.

## Visual remediation strategy

### 1. Remove the failed common grammar

The V2.13A macro city builder is deliberately not invoked.

The new scene contains no shared tower/rail/plaza backbone.

### 2. Hero-dominant composition

Each asset is composed around a sparse macro hero with:
- distinct massing
- distinct negative space
- asymmetric floor
- category-specific horizon
- family-specific landmark silhouette
- category-specific camera distance/elevation
- deterministic theme variant

### 3. Category semantics

- **Universe:** panoramic macro system, detached districts, grand orbital hierarchy.
- **Galaxy:** constellation/navigation graph with deliberate negative space.
- **World:** biome/terrain/habitat silhouette and world landmark.
- **District:** bounded human-scale plaza/street/harbor grammar.

### 4. Material and lighting

Materials remain procedural PBR-like and mobile-aware, but material/palette is not the primary source of differentiation.

Directional lighting is strengthened to separate the hero silhouette from the dark environment.

## Gate

Automated structural visual gate:
- 25 themes per category
- composite silhouette fingerprint (average hash + edge hash)
- threshold remains **0.12**
- threshold is not lowered

Human review remains authoritative after the automated gate.

## Safety

- no Supabase mutation
- no Storage promotion
- no service-role exposure
- no frontend/database changes
- no 350-asset rebuild
- only the 100 macro assets are regenerated
