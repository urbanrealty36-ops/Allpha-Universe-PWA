# V2.13D.5 — Runtime Asset Activation / Consumption Verification

## Status
IMPLEMENTED — RUNTIME VERIFICATION GATE.

## Objective
Prove that the 100 assets promoted by V2.13D.4 are actually consumable by the production runtime through the canonical FastAPI world-runtime manifest and the canonical `AllphaWorldRenderer` consumer.

## Locked scope
- 25 themes
- 4 macro categories: `universe`, `galaxy`, `world`, `district`
- 100 V2.13D.4 GLBs
- Supabase Storage bucket: `allpha-world-assets`
- Storage root: `theme-v2-real-3d/v2.13/`
- renderer: `AllphaWorldRenderer`

D3A, D3C, the other 250 assets, the 350-asset production matrix, database schema, and architecture are not modified.

## Exact runtime path

1. PWA/runtime calls:
   `GET /api/v1/themes/world-runtime/public/themes/{theme_key}/asset-manifest`
2. FastAPI reads authoritative `themes` + `theme_assets`.
3. Only active, approved, passed assets are exposed.
4. FastAPI creates short-lived signed download URLs through the existing Storage service layer.
5. `ThemeV2ProductionAssetScene` selects the exact V2.13D.4 storage path and phase guard.
6. `useGLTF(signed_url)` consumes the production GLB.
7. No service-role secret is exposed to the browser.

## Gate criteria

For every 25 themes:
- manifest is public and presentation-only;
- bucket is `allpha-world-assets`;
- exactly four V2.13D.4 active 3D assets exist in the runtime manifest;
- every expected `theme/category.glb` path exists under `theme-v2-real-3d/v2.13/`;
- every asset has a signed URL;
- signed URL returns a valid GLB header (`glTF`);
- renderer source contains the exact manifest endpoint, V2.13D.4 phase guard, exact storage-path selection, and `useGLTF` consumption.

## Safety
This phase is read-only verification only:
- no Supabase writes;
- no Storage writes;
- no frontend database mutation;
- no secret exposure;
- no rebuild of the 350 matrix;
- no re-run of D3A/D3C.

## First Gate
Run `node scripts/3d/v2-13d5-runtime-asset-consumption-verification.mjs` against the production FastAPI URL.

## Evidence
The workflow uploads `artifacts/v2-13d5/runtime-asset-consumption-report.json` as the authoritative V2.13D.5 evidence packet.
