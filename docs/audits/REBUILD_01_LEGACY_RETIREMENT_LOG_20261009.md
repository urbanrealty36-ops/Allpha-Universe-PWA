## Why the manifest change matters
The previous loader hardcoded `theme-v2-real-3d/v2.13/{themeKey}/{category}.glb`, binding the renderer to the legacy V2.13 Storage layout. The updated resolver no longer requires that prefix, so a future Tripo-generated asset can be delivered from a new versioned prefix while preserving the current authorized public manifest API. It still requires a signed URL and the requested theme/category suffix. No new API, renderer, database, or asset registry was introduced.
