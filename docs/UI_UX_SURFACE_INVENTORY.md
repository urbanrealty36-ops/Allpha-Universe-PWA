## Data rule

These surfaces may render loading, empty, permission-denied, not-configured, and backend-error states. They must not fabricate records to make a screen look populated.

## Runtime rule

UI completion precedes the Green Gate. Real API, Supabase PostgreSQL, authorization, RLS, workflow engines, audit, realtime, E2E, accessibility, and runtime verification are separate completion gates.
