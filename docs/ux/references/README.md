## Design contract

Mobile First PWA is the primary product contract.
Desktop is a responsive expansion of the same product model.
Spatial enhancement is progressive:
2D → 2.5D → Spatial → 3D.

The reference is visual/product direction only. Backend authority remains the canonical FastAPI + Supabase + existing Allpha engine architecture.
